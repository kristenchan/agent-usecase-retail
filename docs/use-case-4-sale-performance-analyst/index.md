# Use Case 4 – Sale Performance Analyst

[← Back to home](../../README.md)

## Scenario

Every store's sales are recorded in one spreadsheet. A sales analyst spends about **an hour every morning** turning it into a sales summary for Management.

It gets even busier during **Mega Sale Week**, when everyone wants answers from the data every day:

- the best day and the top products
- the stores running out of stock
- a quick summary for Management each morning

## Why this agent?

Build **Sale Performance Analyst**, an agent that **analyses Mega Sale sales data using Tailwind Traders' business rules, and creates the daily flash report for Management.**

- **Who it's for:** Finance, Trading & Merchandising, Store Operations, Marketing and Management
- **What it uses:** The Mega Sale sales data (an Excel file with one row per product, store and day)
- **What it does:**
  - Answers questions about sales, products and stores, using Tailwind Traders' business rules (for example, low stock means fewer than 20 units)
  - Calculates every number with code and shows charts
  - Creates the daily flash report for Management in a fixed layout
- **What changes:** Everyone gets answers based on the company's own rules, with numbers that are calculated, not estimated. Management gets the same flash report layout every morning.

Microsoft 365 Copilot already has a built-in **Analyst**. In this use case, you analyse the same file three ways (with Analyst, with your own **Sale Performance Analyst**, and with your agent plus a **daily flash report** skill) and decide which tool fits which job.
